HISTORICAL API CONTEXTWhat the mature video catalogue can inform, but not prove. +

The production system can calculate the catalogue median, mean, and distribution tiers directly from historical video metrics. Use mature-video benchmarks only after an episode has a matched post-publish window.

  • Tier 1: 50M+ impressions
  • Tier 2: 22M–50M
  • Tier 3: 13M–22M
  • Tier 4: 8M–13M
  • Tier 5: under 8M

Guest, topic, title, and format patterns are hypotheses. Ask WTFOS may present them as context, but never as automatic causal findings.
