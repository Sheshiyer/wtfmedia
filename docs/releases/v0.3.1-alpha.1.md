# WTFMedia v0.3.1-alpha.1

This alpha packages the source-link and brand-asset polish for WTF OS.

## Included

- Approved uncut citations preserve their episode-scoped Frame.io URL in the
  public `X-Sources` projection.
- Ask WTF renders an `open Frame.io source` action for those approved URLs and
  preserves the existing published YouTube moment action separately.
- Added the WTF OS browser favicon, Apple touch icon, Android/PWA icons, and
  maskable icon using the existing cream, ink, red, green, and amber brand
  system.
- Added an exact-href browser regression for the uncut source action.

## Boundaries

- Uncut playback and timeline navigation remain explicitly held.
- This alpha is not a production deployment. Production promotion remains a
  separate approved action after PR review and merge.

## Verification

- Root, web, and Worker package versions are aligned at `0.3.1-alpha.1`.
- Web lint, typecheck, contracts, and the focused browser journey pass.
- Production `uncut` chat returned `https://f.io/VrTLEcyQ` in `X-Sources`; the
  destination returned a Frame.io redirect.
