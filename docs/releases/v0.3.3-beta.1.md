# WTFMedia v0.3.3-beta.1

This beta restores the AppRail from alpha, wires the login flow, and adds an
authenticated Ask WTF staging lane with server-side RAG and persisted chat
history.

## Included

- Restored the AppRail contract from the alpha baseline and wired the login
  flow through protected settings.
- Added an authenticated Ask WTF staging lane: turns route through server-side
  RAG, answers are persisted, and chat history is protected behind the staging
  gate.
- Added consolidation policy panels under the operator workspace: memory
  governance, RAG source health, and session history.
- Added a release gate separating the alpha baseline from the beta track so
  authenticated features do not regress public production paths.

## Changed

- Routed beta sign-in through protected settings and hardened the staging
  integration boundary.
- Hidden unverified operator release UI behind the staging gate.
- Edge worker falls back to episode Frame.io links when direct URLs are
  unavailable.

## Deferred

- Production deployment is not included; this beta is a repository tag and
  merged PR (#46), not a Cloudflare deployment receipt.
- Cross-timeline alignment, synchronized uncut playback, and browser-playable
  uncut media remain held from prior alphas.
- No corpus expansion, ingest replay, or Vectorize rewrite is authorized by
  this release.

## Verification

- Cloudflare suite: passing.
- Web typecheck and lint: passing.
- Beta staging lane isolation verified against the alpha baseline.

## Boundaries

This beta is a repository release, not a deployment claim. Production
promotion, secret rotation, DNS changes, and ingest operations remain
separately authorized actions.
