# WTFMedia v0.3.2-alpha.1

This alpha improves evidence selection for named-guest questions and makes
the public source-mode control filter the citations it displays.

## Included

- Added explicit named-person retrieval anchors so questions about Sunil
  Shetty resolve to the matching episode instead of semantically similar
  guests; common one-character spelling differences are tolerated.
- Added truthful abstention when named-person evidence is not present, plus a
  synthesis instruction that prevents substituting another guest or episode.
- Made the public source panel's `published`, `uncut`, and `both` controls
  filter the visible count, list, timestamps, and links from the returned
  citations.
- Preserved episode scope, source identity, and the rule that timestamps are
  never inferred or converted across source modes.

## Deferred

- No additional Frame.io/Vectorize URL propagation, oversized timestamp-line
  chunking, or publisher/re-ingest tooling is included; that new slice is
  explicitly deferred as “won't do now.” Existing `main` behavior is preserved.

## Verification

- Cloudflare suite: 156 tests passed.
- Focused web unit suite: 13 tests passed.
- Web typecheck and lint passed.
- Focused browser source-filter journey passed.

## Boundaries

This alpha is a repository release candidate, not a deployment claim.
Production promotion, ingest replay, Vectorize rewrites, and URL backfills
remain separately authorized actions.
