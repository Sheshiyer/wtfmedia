     - Return sanitized `EpisodeSummaryDTO[]`.
   - Implement `handleGetEpisodeProvenance(req: Request, env: Env, episodeId: string, operator: OperatorRecord)`:
     - Query complete DAG for `episodeId`:
       - Canonical episode entity (`episodes`)
       - External platform identities (`episode_external_identities`)
       - Source media & document assets (`source_assets`)
       - Active & staged transcript versions with segments (`transcript_versions`, `transcript_segments`)
       - Timeline alignments & intervals (`timeline_alignments`, `alignment_intervals`)
       - Search chunks (`transcript_chunks`)
       - Ingestion jobs ledger (`ingestion_jobs`)
     - Privacy Redaction:
       - Strip all raw storage driver paths containing local absolute paths, private bucket names, or credentials.
       - If asset download is requested, generate short-lived pre-signed R2 URL (15 min TTL) gated by operator capability.
     - Return `EpisodeProvenanceDTO`.
   - Implement `handleResolveCitation(req: Request, env: Env, episodeId: string, segmentId: string, targetTimeline: 'uncut' | 'published')`:
     - Resolve segment text, speaker, and time span.
     - Query `timeline_alignments` and call `convertCoordinate` to compute coordinate in `targetTimeline`.
     - Return `CitationResolutionDTO`:
       ```typescript
       export interface CitationResolutionDTO {
         episodeId: string;
         canonicalTitle: string;
         sourceAssetId: string;
         transcriptVersionId: string;
         segmentIndex: number;
         speakerLabel: string;
         quoteText: string;
         sourceTimeSec: { start: number; end: number; system: 'uncut' | 'published' };
         targetTimeSec: { start: number | null; end: number | null; system: 'uncut' | 'published'; status: string };
         isVerified: boolean;
       }
       ```
