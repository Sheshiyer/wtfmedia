  <action>Create typed TypeScript DAL module in `cloudflare/src/db/provenance.ts` exposing atomic D1 repository operations:
    - `upsertEpisode(db: D1Database, episode: NewEpisodeInput): Promise<EpisodeRecord>`: Inserts or updates canonical episode metadata with slug validation and automatic ULID generation (`ep_<ulid>`).
    - `recordExternalIdentity(db: D1Database, identity: NewExternalIdentityInput): Promise<ExternalIdentityRecord>`: Associates platform IDs (YouTube, Drive, Frame.io) with conflict detection.
    - `createSourceAsset(db: D1Database, asset: NewSourceAssetInput): Promise<SourceAssetRecord>`: Registers media/transcript assets with SHA-256 validation.
    - `stageTranscriptVersion(db: D1Database, input: StageTranscriptInput): Promise<TranscriptVersionRecord>`: Inserts transcript version in `staging` state with diarized segments and chunks inside a single transactional batch.
    - `activateTranscriptVersion(db: D1Database, episodeId: string, versionId: string): Promise<void>`: Atomically archives the previous active transcript version (`is_active = 0, state = 'archived'`), activates the new version (`is_active = 1, state = 'active'`), and activates associated search chunks.
    - `resolveCitation(db: D1Database, query: CitationResolveQuery): Promise<ResolvedCitationDTO>`: Resolves episode, transcript version, segment index, and valid coordinate span without exposing private paths (PROV-07).
    - `createIngestionJob(db: D1Database, job: NewIngestionJobInput): Promise<IngestionJobRecord>` and `updateIngestionJob(db: D1Database, jobId: string, update: UpdateJobInput): Promise<void>`.
